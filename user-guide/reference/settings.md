# 设置参考

设置页共八个分组，本页逐项说明用途与默认值。AI 配置的详细用法见[AI 服务配置](../guides/ai-setup.md)。

## 导入与监测

控制会话如何进入 viblogy。

### 监测文件夹

- 添加目录后，出现新的 `.md` 导出文件即自动导入；每行可单独启用/停用或删除（删除不影响已导入的会话）；
- 默认：无监测文件夹。

### Kimi CLI 实时会话监测

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 启用实时监测 | 自动发现并通过 Kimi CLI 同步进行中的会话 | **开启** |
| 监测路径 | 可填绝对路径或 `~/` 开头的路径，留空保存即恢复默认 | `~/.kimi-code/sessions/` |
| 监测时间范围 | 仅监测该时间范围内有内容更新的会话（1 / 12 / 24 小时） | 最近 24 小时 |
| 扫描间隔 | 周期扫描频率；间隔越短发现越快，资源消耗越高（1 分钟 ~ 8 小时十档） | 5 分钟 |

启用实时监测时若同时开着文件夹监测，会提示两者可能重复导入，并可一键关闭文件夹监测。

### Qwen Code 实时会话监测

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 启用 Qwen Code 监测 | 与 Kimi 监测相互独立，可单独开关；关闭后已导入的会话不受影响 | **开启** |
| 监测路径 | 填 projects 根目录，留空保存即恢复默认 | `~/.qwen/projects/` |

### AI 自动摘要

- **Wire 会话自动生成 AI 摘要**：实时会话新轮次入库后自动理解、归纳并生成总摘要（会产生 AI 调用费用）。未配置激活的 AI 服务时不可开启。默认：**关闭**。

## AI 服务

### 配置管理

- 可保存多套配置；下拉切换，激活方式为「测试激活」（保存、设为激活并测试连接）；
- 云端模式：10 家服务商预设、API Key、基础 URL（可手动修改）、模型（可从服务端拉取列表）、思考模式（仅 kimi-k2.5/k2.6）、自定义请求头（高级选项）；
- 本地模式：Ollama 地址（默认 `http://localhost:11434`）与本地模型名；
- 详见[AI 服务配置](../guides/ai-setup.md)。

### AI 回答风格

控制语言直白度与认知深度，不减少信息量。三档：**入门**（默认）/ 进阶 / 专业。

### AI 输出长度预算

Turn 理解、AI 梳理、代码注解与 Flowchart 解读的输出 token 上限。档位：不设限 / 512 / 1024 / 2048 / **4096（默认）**。输出被截断时自动以翻倍预算重试一次。

### 摘要格式

段落式（叙事型：背景、过程、决策、成果）与清单式（分点罗列完成事项），可多选，至少保留一种。默认：**仅段落式**。

## 代码库

### 代码树扫描

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 扫描节点上限 | 超过上限时扫描截断 | 2000 |
| 扫描深度上限 | 目录扫描的最大层级（1~20） | 8 |
| 单文件读取阈值 (MB) | 超过此大小的文件跳过内容读取 | 2 |

### AI 代码标注

- **启用 AI 代码标注**：关闭后不再读取或发送任何代码文件内容，已有注解仍可查看但无法重新生成。默认：**开启**。

### Flow 解释注入强度

生成 Flow 解释时参考的 Turn 理解数量：精确（约 3×节点数条）/ 平衡（2×）/ **经济（1×，默认）**。仅影响之后生成的 Flow 解释。

## 会话

| 设置项 | 说明 | 默认值 |
|---|---|---|
| Session 轮次上限 | 超过该轮次的会话自动拆分为 Part（10 / 20 / 30 轮） | 20 轮 |
| 未生成摘要时的会话标题 | 会话 topic / 最后一次 user 发言 / 跟随时间线开关；已有摘要的会话始终显示摘要标题 | 会话 topic |
| 显示首个用户发言 | 在标题下方显示首个 Turn 的首次用户发言作为浅色小标题 | 关闭 |

## 外观

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 主题 | 浅色 / 深色 / 跟随系统 | 跟随系统 |
| 全局字号 | 12~20px 滑块，调整所有界面文字的基础大小，层级比例不变 | 16 |

## 授权许可

授权码激活、试用状态、授权信息与账号切换入口。详见[试用与激活](../getting-started/trial-and-activate.md)与[授权与账号](../guides/license-account.md)。

## 数据与反馈

- **数据备份**：导出完整备份（zip）/ 导出 JSON 元数据 / 恢复备份。详见[备份与恢复](../guides/backup-restore.md)；
- **搜索索引**：派生数据，通常无需维护；搜索行为异常时可「重建搜索索引」；
- **快捷键**：搜索 = `⌘K`；打开设置 = `⌘,`；导入文件 = `⌘⇧I`；
- **数据与隐私**：数据全部存储在本机（`~/Library/Application Support/com.viblogy.app/`），不上传云端；云端 AI 服务仅发送对应功能所需的内容；API Key 保存在本地；
- **意见反馈**：填写反馈表单发送给开发者。

## 已归档项目

恢复已归档的项目；恢复后项目重新出现在左侧栏，其会话原样回来。

## 不在设置页的视图控件

这些开关在各自的面板上，同样会被记住：

| 控件 | 位置 | 默认 |
|---|---|---|
| 会话速览走马灯 | 速览目录面板标题栏 | 开启 |
| 轮次顺序（最早在上 / 最新在上） | 左侧栏「时间线」行内按钮 | 最早在上 |
| 内容显示侧（用户输入 / assistant 回复） | 左侧栏「时间线」行内按钮 | 用户输入（应用重启后回到默认） |
