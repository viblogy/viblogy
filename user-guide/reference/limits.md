# 限制与默认值

用户可感知的数值边界速查。全部数值已对照代码核实（基准版本 v0.10.1）；此处只列用户可见的部分，实现层面的内部限制不在此列。

## 时间线

| 项 | 数值 | 说明 |
|---|---|---|
| 时间线显示的会话组上限 | **500 组** | 超出时只显示最近活跃的部分，横幅引导用搜索（⌘K）找回更早会话；搜索与跳转不受此限制 |
| 超长会话拆分阈值 | 每 Part **20 轮**（可选 10/20/30） | 见「设置 → 会话 → Session 轮次上限」 |

## 代码树扫描

| 项 | 默认值 | 可调范围 |
|---|---|---|
| 扫描节点上限 | **2000** | ≥1；超限时截断并提示 |
| 扫描深度上限 | **8** 层 | 1~20 |
| 单文件读取阈值 | **2 MB** | ≥0.1 MB；超过的文件跳过内容读取 |

扫描默认跳过：`.gitignore` 中的内容，以及 `node_modules`、`target`、`dist`、`build`、`.git`、`.next`、`out`、`coverage` 八个目录；多选模式可把指定节点加入 `.gitignore` 排除。

## 实时监测

| 项 | 默认值 | 范围/档位 |
|---|---|---|
| 扫描间隔 | **5 分钟** | 1 分钟 / 2 分钟 / 5 分钟 / 10 分钟 / 15 分钟 / 30 分钟 / 1 / 2 / 4 / 8 小时 |
| 监测时间范围（Kimi） | **最近 24 小时** | 1 / 12 / 24 小时 |

监测文件夹（.md 自动导入）没有扫描间隔设置——它基于文件变化即时触发，另在每次启动时扫描一次补齐遗漏。

## 搜索

| 项 | 数值 |
|---|---|
| 每个关键词最短 | **3 个字**（过短会提示并拒绝） |
| 关键词总长上限 | 100 字符 |
| 单次最多关键词数 | 8 个（逗号分隔） |
| 推荐词 | 每屏 8 个，「换一批」翻页；词源为近 30 天 |

## AI 功能

| 项 | 数值 |
|---|---|
| 输出长度预算 | 不设限 / 512 / 1024 / 2048 / **4096（默认）**；截断时自动翻倍重试一次 |
| 一键补齐理解的预估速度 | 每轮约 **30 秒**（仅用于预估耗时） |
| 摘要断点续跑 | 中断后显示「分组归纳未完成，点击继续」，不限次数 |

## 试用与授权

| 项 | 数值 |
|---|---|
| 试用期 | **30 天**（全安装级，切换账号不重新开始） |
| 到期提醒 | 剩余 **7 天**以内出现横幅 |
| 延期码天数 | 由发放方决定，可多次累计 |

## DevPlan 计划文档

| 项 | 数值 |
|---|---|
| 支持格式 | `.md` / `.markdown` / `.txt`（UTF-8 编码） |
| 文件大小上限 | **256 KB** |

## 备份与启动

| 项 | 说明 |
|---|---|
| 备份文件名 | 完整备份 `viblogy-backup-日期时间.zip`；元数据 `viblogy-backup-日期.json` |
| worktree 启动命令长度 | 不超过 500 字符 |
| 详情侧栏宽度 | 默认 320，可拖拽（最小 260，最宽约到窗口一半） |
