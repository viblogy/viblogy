# 常见问题

按场景组织的常见问题与解决办法。

## 安装与启动

**打开应用时遇到 Gatekeeper 提示？**
viblogy 已通过 Apple Developer ID 签名与公证，正常可直接打开。若仍有提示：系统设置 → 隐私与安全性 → 找到相关提示 → 「仍要打开」。详见[安装与首次启动](../getting-started/install.md)。

**数据存在哪里？**
全部保存在本机，不会上传到任何服务器。使用云端 AI 服务时，相关对话内容会发送给你配置的 AI 服务商。

## 试用与授权

**试用到期了怎么办？**
应用进入锁定页，数据完好保存在本地。输入授权码激活即恢复；也可以输入其他账号的授权码切换账号。详见[试用与激活](../getting-started/trial-and-activate.md)。

**延期码在哪里兑换？**
与授权码同一入口（设置 → 授权许可）：粘贴延期码点「激活」即可，时长累计；到期后兑换也能解锁。延期码须属于当前账号。

**提示「该授权码属于其他账号」？**
授权码一码一账号、时长不可叠加。确认后即切换到该账号：已有账号数据原样恢复，新账号从空白开始；当前账号数据保留，重新输入它的码即可切回。详见[授权与账号](../guides/license-account.md)。

## 导入与监测

**导出文件放在子目录里，监测不到？**
监测与启动扫描只在文件夹**第一层**寻找 `.md` 文件。请把导出文件直接放在监测目录下。详见[导入与整理](../guides/import-and-organize.md)。

**重复导入同一会话会怎样？**
手动导入遇到更新版本时弹「检测到会话更新」，可选合并更新（保留 AI 成果）或作为新会话导入；完全相同的内容直接跳过。监测导入则自动更新并清理旧版本。

**开启了实时监测，新会话一直不出现？**
依次检查：对应 CLI 是否在运行；会话是否在监测目录范围内（可在设置中查看/修改监测路径）；点时间线顶部的刷新按钮立即扫描一次。详见[开启实时监测](../getting-started/live-monitor.md)。

## AI 功能

**提示「分组归纳未完成，点击继续」？**
超长会话的摘要生成被中断（退出应用、网络问题等），点击即从断点继续，已完成的归纳不会重复生成。

**提示输出相关错误（如「思考内容已耗尽输出预算」）？**
调高「设置 → AI 输出长度预算」（默认 4096）。输出被截断时 viblogy 会自动翻倍重试一次，重试仍截断才会提示。

**所有 AI 功能都提示未配置？**
先在[AI 服务配置](../guides/ai-setup.md)中新增并「测试激活」一份配置。

**理解/摘要生成太慢？**
批量任务可继续使用其他功能，进度在底部状态栏；可随时暂停/取消，恢复后从断点继续。

## 代码地图

**某个文件为什么没有数据流边？**
常见原因：文件没有 import/导出语句（纯脚本或配置）；语言不在支持范围（Rust / TypeScript 系 / Python）；引入的文件不在项目内。可先点「刷新扫描」。详见[数据流与解读](../guides/dataflow.md)。

**注解显示「旧注解」？**
文件在扫描后发生了变化，点注解段首的刷新图标重新生成即可。详见[代码树与注解](../guides/code-tree.md)。

**删除过的文件还在关联里？**
对话关联保留历史：树上找不到节点的路径会出现在代码树底部的「历史路径」区。详见[影响关联与溯源](../guides/impact-links.md)。

## 备份与恢复

**恢复备份为什么要输入授权码？**
身份验证：授权码必须属于备份记录的所属账号（无账号记录的旧备份则需当前账号的码）。只验身份，不验授权是否过期——授权过期也能找回自己的备份。详见[备份与恢复](../guides/backup-restore.md)。

**恢复提示「与当前账号不一致」？**
该备份属于另一个账号。确认归属后再继续；恢复会替换当前账号的全部数据（恢复前自动快照兜底）。

## 还没解决？

通过应用内反馈入口提交（设置 → 数据与反馈），或参考[功能总览](../concepts/overview.md)找到对应功能章节。
