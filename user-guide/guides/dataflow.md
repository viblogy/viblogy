# 数据流与解读

从「看懂单个文件」到「看懂数据怎么流动」：上下游链条、数据流图、两节点间的 AI 解读。

## 上下游链条

选中文件后，行内详情顶部是一条横向链条：

`[flowchart] 上游文件 → 本节点 → 下游文件`

- 上游浅蓝底、下游浅绿底，每侧最多直列 3 个，超出折叠为「+N」；
- 点击邻居文件，在树中定位并选中它；
- 关联关系从项目的 import 语句自动解析得出，支持 **Rust、TypeScript 系（含 TSX/JSX/JS/Vue）、Python** 项目。

## Flowchart 数据流图

点击链条行最左侧的「**flowchart**」按钮打开（覆盖代码树区域）：

- 纵向三层：**上游 / 焦点节点 / 下游**，箭头指示数据流向；
- 点击邻居卡片即切换焦点（上一焦点以蓝色描边强调）；
- 同目录的邻居文件过多时折叠为目录盒（「📁 目录名 · N 个相关文件」），点击展开；
- 每张卡片右上角有「在代码树中定位」按钮；测试文件默认隐藏，右上角开关可显示；
- 关闭：右上角 ✕ 或按 Esc；
- 底部悬浮面板两个页签：「节点详情」与「图景解读」。

无数据流关联时显示空态与排查提示（文件没有 import 语句 / 语言不在支持范围 / 引入的文件不在项目内）。

## 边上的数据标签

图的边可以由 AI 标注「流的是什么数据」（边中段的圆角标签）：

- 查看时会自动在后台补齐；
- 也可手动发起：flowchart 右上角「生成数据流标签」，确认框显示将处理的边数；关联文件缺注解时会先自动补齐。

## 图景解读（两节点解读）

任选两个节点，AI 为你解释它们之间的关系：

- **中观描述**：描述焦点节点邻域图景中各文件的角色。「图景解读」页签 →「生成中观描述」；缺注解的文件会先自动补齐（确认框中注明数量）；
- **Flow 解释**：讲清两个节点之间数据如何流动、这条路诞生于哪次对话。右上角开启「解读模式」→ 依次点击两张卡片选择起点与终点 → 自动寻路后确认（显示路径与将注入的 Turn 理解数）→ 生成；缺失的理解可选「自动补充」或「跳过」；
- 图景中只有两个节点时请求中观描述，会弹出建议框：改道生成这两节点之间的 Flow 解释；
- **依据过期**：相关代码或理解发生变化后，解读显示「已过期」徽标，建议重新生成；
- 两节点之间没有路径：提示「这两个节点之间没有数据流路径」，可尝试反向选择或重新选择。

解读中引用的会话与轮次可以直接点击跳转。

## 未提交改动与 worktree

项目视图右栏：

**Worktree 与分支状态**（按 worktree 分组）：分支名、相对追踪分支的领先/落后数，以及两个可折叠列表——

- 「N 条提交」：点击某条提交懒加载其改动文件（树内文件按四类着色、点击定位；树外文件置灰）；
- 「N 个未提交改动」：状态字母 + 路径，点击在树中定位。

每个 worktree 条目有「在终端中启动」按钮：确认目录与启动命令（可勾选「保存为项目默认启动命令」），在终端中启动项目。

**AI 梳理**：对近期未提交改动生成一段可读的梳理（纯文本、分节可折叠）；有新改动时显示「· 有新输入」，点击图标重新梳理。

## 常见问题

**某个文件为什么没有数据流关联？**
常见原因：文件没有 import/导出语句（纯脚本或配置）、语言不在支持范围（Rust / TypeScript 系 / Python）、或它引入的文件不在项目代码树中。可先点「刷新扫描」重试。
