# 影响关联与溯源

对话与代码之间的双向缝合：从文件看到哪次对话改了它，从对话看到它影响了哪些文件。

## 正向：从文件到对话

- 代码树行尾显示关联计数徽章（悬浮提示「N 次对话关联」）；「关联密度」排序下，关联数不少于 5 的节点徽章变为琥珀色；
- 选中节点，行内展开的详情右列是「对话关联」：
  - 每条：会话主题 + 「第 N 轮」+ 置信标签（精确 / 片段）+ 时间；
  - 由摘要推断而来的条目带紫色「AI 推断」徽标，并附一行匹配依据；
  - **点击条目**：跳转到该轮对话的原文视图，返回时间线时自动定位；
  - 悬停条目可删除（删除 AI 推断关联后，重新生成摘要可能再次建立该关联）。
- 无关联时显示「还没有对话关联到这里」。

### 历史路径区

树底部有折叠的「历史路径」区：对话中提到过、但在代码树中找不到（或文件已删除）的路径，每条显示「N 次对话」；展开后同样可以查看关联、跳回对话。

## 反向：从对话到文件

- **轮次卡片底部**有「影响」chips：该轮对话影响到的文件，最多 3 行，溢出显示总数；
- **原文视图底部**有「影响代码节点 (N 个)」折叠块，附带分类图例：前端（蓝）/ 后端（绿）/ 配置（琥珀）/ 文档·测试（灰）；
- 点击任一 chip：跳转项目视图，逐层展开并在代码树中高亮定位该文件。

## 关联何时产生

- 会话导入、实时同步入库后自动关联：对话中提到的文件路径会配对到代码树节点；**无法确定的不强行关联**；
- 存量会话可用「补挂关联」补齐（见下）；
- 会话摘要生成完成后，还会根据摘要内容补充「AI 推断」关联（置信较低、有专门徽标）。

## 补挂关联

项目视图顶栏「补挂关联」：点击立即开始（无确认弹窗），绿色进度条显示「补挂中 N/M 会话」与「N 关联 / N 历史」计数；可随时点「停止」中断，之后再次点击即从中断处继续（已完成的轮次不会产生重复关联）。进度条消失即完成。

## 常见问题

**「AI 推断」关联和别的有什么不同？**
它是根据摘要内容匹配出来的低置信补充，带专门徽标与匹配依据，可以单独删除；对话中直接出现的路径建立的关联标记为「精确」或「片段」。
