# 问答与翻译

对读过的会话直接追问；对长段落做翻译与解读。

前置条件：已[配置 AI 服务](./ai-setup.md)。

## Session 问答

入口：会话卡片最大化进入详情视图 → 右侧栏「**问 AI**」页签。

### 提问

- 输入问题后点「发送」（或回车），AI 基于该会话的完整上下文作答；
- 需要引用特定轮次的原文时，在问题里输入 `@turn` + 轮号，三种写法都支持：
  - `@turn 1,2,3` —— 指定多个轮次
  - `@turn 1-4` —— 指定范围
  - `@turn 1,3-5,7` —— 混合
- 勾选输入框下方「混合模式」：@turn 时同时附带其余轮次的 AI 理解作为上下文；
- AI 回答中有时给出推荐轮次圆片（如「Turn 12」），点击会自动把 `@turn N` 填入输入框；
- 首次使用可参考四个快捷提问：总结关键决策 / 找出待办事项 / 解释核心思路 / 提炼代码变更（点击填入输入框）。

### 问答历史

- 问答保留在面板中（问题右侧、回答左侧）；回答生成时可展开查看思考过程；
- 「**置入笔记**」：把整段问答历史一键存为笔记；
- 「清空」：清空当前会话的问答历史；
- 问答仅基于当前会话的上下文，跨会话提问暂不支持。

## 段落翻译与解读

在原文视图（轮次卡片悬停 →「查看原文」）与笔记详情中，可以对任意段落做 AI 翻译或解读。

### 操作步骤

1. **选段落**：点击段落选中（段首出现勾选标记），再点一次取消；Shift+点击选择区间；点击标题选中整节；
2. 点顶栏「**翻译**」按钮（蓝色）或「**解读**」按钮（琥珀色）；
3. 结果以批注卡片形式出现在对应段落右侧，连续段落合并为一组。

### 批注卡片

- 卡片标注模式（翻译 / 解读）与段落数量；处理中显示「AI 处理中...」；
- 失败时显示「重试」；点「×」关闭该条批注；
- 点击批注卡片正文，反向定位到原文段落；
- 批注长期保存、不会过期，按需逐条关闭即可。

顶栏还提供：全选、复制（纯文本 / markdown / txt）、清空选择。

## 常见问题

**批注会过期吗？**
不会。批注保存后长期有效，需要清理时逐条关闭。
