# 代码树与注解

确认项目代码文件夹后，viblogy 把项目扫描成代码树：浏览结构、看 AI 注解、查看每个文件的状态。

## 浏览代码树

- 逐层展开/收起；**选中文件时，详情就在该行下方就地展开**（元数据 | AI 注解 | 对话关联三列）；
- 行上的状态徽标（优先级从高到低）：
  - 红色「冲突」：文件存在 git 冲突；
  - 黄色「未提交」：文件有未提交改动；
  - 灰色「旧注解」：该文件的注解已过期。
- 文件图标按类别着色（前端 / 后端 / 配置 / 文档·测试）；选中文件时元数据行显示文件大小与语言；
- 顶栏状态筛选：全部 / 未提交 / 旧注解；排序：默认 / 关联密度（关联多的节点靠前，关联数不少于 5 的节点徽章变琥珀色）。

## AI 注解

每个文件/目录可以获得 1~3 句中文注解，说明它「存什么数据、造什么功能、负责什么模块」。

- **自动生成**：选中或展开节点时，若无注解会自动在后台生成（显示「生成中…」）；
- **重新生成**：注解段首的刷新图标；扫描后文件发生变化时，注解会标为「旧注解」；
- **标注全部**（顶栏）：弹窗显示待标注数量——「还有 N 个节点未标注……已标注的节点不会重复处理」；开始后顶栏下方显示进度「标注中 N/M」与失败数；可随时停止，之后再次点「标注全部」即从中断处继续；
- 目录注解由子级注解汇总而来；子级注解不全时显示「部分依据」徽标。

隐私护栏：

- 生成注解只读取文件头部与符号清单，**不发送整个文件**；
- 「设置 → 启用 AI 代码标注」可整体关闭：关闭后不再读取或发送任何代码文件内容，已有注解仍可查看，但无法重新生成。

## 顶栏其他操作

- **刷新扫描**：重新扫描项目（扫描中显示「正在扫描项目代码…」）；
- **多选**：进入多选模式管理扫描排除项——勾选节点后「忽略选中」会写入项目 `.gitignore` 并自动重新扫描；「取消忽略」移除对应规则；
- **补挂关联**：见[影响关联与溯源](./impact-links.md)。

## 扫描规则与限制

- 扫描尊重 `.gitignore`，并自动跳过常见构建产物目录；
- 节点数超过上限时截断并提示：「节点过多，本次只扫描了前 N 个，可在设置中调整上限」（上限设置见设置参考，撰写中）。

## 常见问题

**注解为什么变灰显示「旧注解」？**
文件在扫描后发生了变化，点注解段首的刷新图标重新生成即可。
