# Debug 复盘

对一场来回排查的 debug 会话，生成复盘报告：根因、排查过程、修复策略、教训总结，并把结论落到具体文件。

前置条件：已[配置 AI 服务](./ai-setup.md)。

## 生成入口

会话详情 → 右侧栏「**复盘**」页签 → 「开始 Debug 复盘」。

若会话缺少 Turn 理解，会先弹出「补全 Turn 理解」：按顺序自动补全后再继续。

任何会话都可以生成复盘；若会话没有明显的 debug 过程，结果会显示「本次会话未涉及明显 debug 过程，可能是一次轻松的对话」。

## 生成过程

- 面板显示「正在分析 Debug 过程...」；底部状态栏有聚合进度（「Debug 复盘 N/M」），AI 工作区可看各阶段明细；
- 可随时在状态栏暂停或取消，恢复后从断点继续、不重复已完成的分析。

## 复盘结果

顶部显示「共发现 N 个 Debug 意图」，每个意图卡片含四个可折叠分区：

1. **根因分析**
2. **排查过程**
3. **修复策略**
4. **教训总结**

以及：

- **关键路径**：列出关键轮次与支持轮次，各附「为什么重要」说明；点击任一轮次直达对应对话；
- 「复制」：复制完整复盘报告；
- 「导出」：保存为 Markdown 文件。

::: tip 导出范围
导出的报告包含四个分区与关键路径，不含下方的代码锚定信息。
:::

## 代码锚定

会话归属了项目且有代码树时，复盘结论会进一步落到代码：

- **根因文件**：文件名标签。蓝色标签可点击，跳转项目视图代码树并定位该文件；灰色表示代码树中未找到该文件；
- **涉及代码文件**：可折叠列表，逐条显示文件注解与关联证据。

会话没有项目归属或代码树时，这两部分不显示，复盘照常生成。

## 旧版结果

早期版本生成的复盘不含代码锚定，卡片显示「未锚定代码文件」徽标与「重新生成」按钮；重新生成会覆盖旧结果。

## 常见问题

**生成失败怎么办？**
面板会显示错误原因与「重试」按钮；若因暂停中断（「AI 任务已暂停」），在状态栏恢复后从断点继续。
