# 笔记

把会话里淘到的结论沉淀成笔记：手动创建，或从 AI 理解、问答中一键保存。

## 笔记列表

左侧栏「笔记」：蓝色描边卡片（斜体标题 + 内容预览 + 日期 + 标签圆片）；顶栏有标题搜索框与「+ 新建笔记」。

列表跟随左侧栏的项目过滤（点项目名就地过滤，不离开笔记视图）。

## 创建笔记

三种途径：

1. **手动创建**：「+ 新建笔记」，填写标题、标签（逗号分隔）、正文（Markdown）；
2. **从 Turn 理解**：轮次卡片的理解块上点「置入笔记」，理解内容存为笔记（自动归入会话所属项目）；
3. **从 AI 问答**：问答面板点「置入笔记」，整段问答历史存为笔记。

## 笔记详情

点击卡片进入详情（Markdown 渲染）：

- 顶栏支持选段落后**翻译 / 解读 / 复制 / 全选**（与原文视图同一套操作，见[问答与翻译](./qa-and-translate.md)）；
- 「编辑」按钮进入编辑页修改（保存后回到详情）；
- 「删除」有确认，删除后无法恢复。

## 常见问题

**笔记支持什么格式？**
Markdown。正文按 Markdown 书写，详情中渲染预览；复制时可选纯文本 / markdown / txt 三种方式。
