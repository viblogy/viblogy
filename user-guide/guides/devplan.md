# DevPlan 计划清单

把开发计划文档变成结构化任务清单；AI 从对话中自动判定任务进度，每个「完成」都有对话证据。

前置条件：已[配置 AI 服务](./ai-setup.md)（自动判定在 Turn 理解生成后触发）。

## 创建清单

入口：会话详情右侧栏置顶的「**开发任务清单**」面板。没有清单时提供两种方式：

### 从文档导入

1. 点「从文档导入」，选择计划文档（支持 `.md` / `.markdown` / `.txt`，不超过 256 KB）；
2. AI 阅读文档、抽取任务（「AI 正在阅读文档…」，文档较长时可能需要十几秒）；
3. 确认界面显示「AI 从《文件名》里读出了 N 条任务，请过目」，逐条可：
   - 取消勾选以剔除；
   - 直接编辑标题；
   - 拖拽排序；
   - 展开「说明」查看原文上下文；
4. 默认勾选「导入后对已有的 N 段理解追溯判定进度」（为已有对话补判进度）；
5. 点「确认导入」。

特殊情况：

- 该会话已有使用中的清单：导入新文档会先把旧清单归档（只读），确认后继续；
- AI 没认出任务：提示「没有认出开发任务」，换一份计划文档；
- 该文档导入过：可选「仍然重建清单」。

### 手动新建清单

输入清单标题创建，之后逐条添加任务。

## 任务状态与 AI 判定

每条 Turn 理解生成后，AI 自动跟随判定任务进度：

- 判定「推进了」→ 任务标记「**进行中**」（琥珀徽标）；
- 判定「做完了」→ **不自动勾选**，而是给出待确认建议：「AI 认为这条已完成（把握 N%）：理由（依据第 N 段对话）」，附「接受」/「驳回」按钮；
- 接受 → 任务完成，徽标「AI 完成」；手动勾选的显示「手动完成」；
- **驳回后，AI 不再对该任务自动建议**（永久豁免）。

清单标题旁 ⋯ 菜单提供「接受全部建议 (N)」（有确认）与「重新追溯判定」。

## 进度横幅

展开关联了使用中清单的会话时，时间线顶部出现进度横幅：清单标题 + 进度条 + 完成数（如 `3/8`）+「N 条待确认」（有建议时）。点击横幅定位到清单面板；会话卡片上另有青色「Todo」徽标。

## 点任务找对话

有判定留痕的任务行可点击，进入筛选模式：时间线只显示该任务关联的对话（顶部提示「正在查看：任务『任务名』关联的 N 段对话」），主要完成轮次高亮标记「主完成段」；点 × 退出筛选。无留痕的任务会提示「无关联对话」。

## 跨会话共享清单

会话没有清单、且已有项目归属时，面板会自动列出同项目下其他使用中的清单，点「关联」即可共享。关联后各会话看到同一份任务与同一组进度。（关联目前不支持手动解除。）

## 清单管理

清单标题旁 ⋯ 菜单：重新追溯判定 / 接受全部建议 / 从文档导入… / 重命名 / 归档 / 删除清单。

- **归档**：清单变为只读，面板回到无清单状态，可为后续开发新建清单；
- **删除**：清单与全部任务永久删除（有确认）。

## 常见问题

**进度为什么没有自动更新？**
自动判定由 Turn 理解触发。用会话速览的「一键校正」补齐理解，或在清单菜单中「重新追溯判定」。
