# 备份与恢复

整个资产库可以导出为一个 zip 备份文件，随时完整恢复。

## 导出备份

「设置 → 数据与反馈 → 数据备份」：

- **导出完整备份（zip）**：包含全部数据（数据库与内容文件），默认文件名 `viblogy-backup-日期时间.zip`；
- **导出 JSON 元数据**：仅项目、设置等元数据，**不含**会话与笔记全文；
- 完整备份会记录它所属的账号，恢复时供预览与身份验证使用。

::: warning 备份文件包含你的全部数据
其中含 API Key 等敏感配置，请妥善保管、避免泄露。
:::

## 恢复备份

1. 点「**恢复备份**」，选择 `.zip` 或 `.json` 备份文件；
2. **只读预览**：备份类型、导出时间、来源版本、所属账号、内容规模（N 个会话 / N 个 Turn / N 条笔记 / N 个项目 / N 项设置）；
3. **授权码身份验证**：输入备份所属账号的授权码——
   - 授权码必须属于备份记录的所属账号；
   - 没有账号记录的旧备份，输入当前账号的授权码；
   - 只验证身份，不验证授权是否过期；未输入无法确认恢复；
4. **确认恢复**：
   - zip 完整备份：**整体替换**当前账号的全部数据，回到备份时刻的状态（不可撤销）；
   - JSON 元数据备份：仅恢复元数据；
5. 恢复前自动为当前数据创建快照；完成后的对话框会给出快照路径，**重启应用后生效**。

备份所属账号与当前账号不一致时，预览页会明确警示：「恢复将替换当前账号的全部数据，请确认备份归属后再继续」。

恢复完整备份并重启后，实时监测的会话会按源文件自动重新同步，无需手动操作。

## 常见问题

**恢复失败会丢数据吗？**
不会。恢复失败提示「数据未被修改」；若恢复前的自动快照失败，恢复会直接中止。

**旧版本导出的备份（没有账号记录）能恢复吗？**
可以，但身份验证时需提供**当前账号**的授权码；当前账号未激活（无授权邮箱）时无法验证身份，需先激活。
