# 项目与归档

项目是会话库的组织轴：会话归属到项目，代码树按项目建立，做完的项目可以归档藏起来。

## 创建项目

唯一手动入口：左侧栏底部「**+ 新建项目**」→ 输入名称 → 「创建项目」（回车也可提交）。

项目也会自动创建：自动归属识别到新的项目名时，会直接建立对应项目。

## 项目视图

点左侧栏「项目」导航进入：

- 进入时自动选中第一个项目（按名称排序）；若此前看过某个项目，则直接打开它；
- 顶栏：项目名、代码文件夹路径、搜索、状态筛选（全部 / 未提交 / 旧注解）、排序（默认 / 关联密度），以及「多选」「刷新扫描」「标注全部」「补挂关联」等操作；
- 主体是代码树，右侧为节点信息面板（宽度可拖拽）。

代码树、AI 注解与影响关联的详细用法见「代码地图」系列章节（撰写中）。

### 确认代码文件夹

尚未确认代码文件夹的项目，进入项目视图会弹出「**确认项目代码文件夹**」：

- 弹窗列出将要扫描的文件夹，并说明扫描目的——构建代码树，看清项目结构以及每次对话改动了哪些位置；
- 只读取文件夹结构与文件元信息，不会上传任何文件内容；
- 可选「确认并开始扫描」「换一个文件夹…」「取消（下次再问我）」；
- 确认后立即开始扫描（显示「正在扫描项目代码…」）。

已确认的项目在顶栏显示当前文件夹路径；**点击路径**即可更换文件夹（选择后立即重新扫描）。

### 扫描范围与上限

扫描尊重 `.gitignore`，并自动跳过常见构建产物目录（如 `node_modules`、`dist` 等）。

项目过大时扫描会截断并提示：「节点过多，本次只扫描了前 N 个，可在设置中调整上限。」相关设置（设置 → 代码库）：

| 设置项 | 默认值 |
|---|---|
| 扫描节点上限 | 2000 |
| 扫描深度上限 | 8 |
| 单文件读取阈值 | 2 MB |

## 项目归档

做完的项目不想看见、又不想删数据，用归档：

1. 悬停左侧栏项目行，点击出现的归档图标；
2. 确认提示：「归档后项目将从左侧栏隐藏，可在设置中恢复。」

归档后的效果：

- 项目从左侧栏消失；
- 它的会话在时间线、搜索结果、实时监测会话列表等入口统一隐藏；
- **笔记不受影响**；
- 数据不会删除：会话、注解、影响关联等全部保留。

## 恢复归档项目

「设置 → 已归档项目」：每行显示项目名与「恢复」按钮。恢复后项目回到左侧栏，其会话原样回来。

## 常见问题

**项目能删除吗？**
不能。项目只能归档（可随时恢复）——这也是有意的设计：归档项目的数据在备份中同样完整。

**归档后搜索也找不到了？**
是的，归档项目的会话在搜索结果中一并隐藏；恢复项目后即可找回。
