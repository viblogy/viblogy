# AI 服务配置

摘要、Turn 理解、问答、代码注解、Debug 复盘——所有 AI 功能都依赖这里配置的 AI 服务。

## 前置条件

一个可用的 AI 服务 API Key，或本机运行的 Ollama。

## 新增配置

「设置 → AI 服务 → 新增配置」（首次启动引导第 4 步同样可以配置）。表单内容：

- **配置名称**：任意名字，例如「Kimi Code 工作号」；
- **服务模式**：云端 / 本地 Ollama；
- **服务商**（云端模式）：从 10 个预设中选择，自动填好端点与默认模型，只需输入 API Key：
  Moonshot / Kimi（国内站）、OpenAI、DeepSeek、智谱 GLM（国内站）、通义千问 / 阿里云百炼、SiliconFlow（硅基流动）、OpenRouter、Anthropic（OpenAI 兼容端点）、Gemini（OpenAI 兼容端点）、自定义（OpenAI 兼容）；
- **API Key**；
- **API 基础 URL**：预设自动填充，也可手动修改（改动后标「已手动修改」）；输入框下方预览最终请求地址，排查连接问题时对照检查；
- **模型**：手动输入，或点 ⟳ 从服务端拉取可用模型列表；
- **思考模式**：仅对 Moonshot kimi-k2.5 / k2.6 生效（推荐配置 / 强制思考 / 强制非思考）；
- **高级选项 → 自定义请求头**：追加额外 HTTP 头（不可覆盖 Authorization 与 Content-Type）。

选择「本地 Ollama」模式时：填写 Ollama 地址（默认 `http://localhost:11434`）与本地模型名；模型需提前拉取（`ollama pull 模型名`）。

## 测试与激活

- 设置页按钮是「**测试激活**」：保存配置、设为激活项并测试连接；引导页是「测试连接」（只探测、不保存）。
- 成功提示：「连接成功！模型：xxx，延迟：N ms」。
- 失败时给出具体原因，常见的有：
  - API Key 无效或无权限；
  - 路径不存在（检查 Base URL 是否多带或少带了 `/v1`，对照「最终请求地址」）；
  - 连接超时（检查网络，或确认该服务商是否需要代理）;
  - 网络不可达；
  - 服务返回格式不兼容。
- 展开「查看调试信息」可看原始错误。

## 多配置管理

- 可保存多套配置，「当前配置」下拉切换，激活项标「（当前使用中）」；
- 激活方式：修改配置后点「测试激活」（引导页为「创建并激活」）；没有单独的「设为激活」按钮；
- 「保存修改」只保存不测试；「删除」移除配置（有确认），删除后自动激活剩余第一条配置。

## AI 回答风格

「设置 → AI 回答风格」，三档：

- **入门**（默认）：知道发生了什么——做了什么、为什么做，术语配白话解释；
- **进阶**：理解怎么做与取舍——实现机制、Trade-offs 与被舍弃的替代方案；
- **专业**：洞察底层与边界——精确语义、边界条件与最佳实践。

风格控制语言直白度与认知深度，不减少信息量。理解与摘要面板会显示当前档位徽标。

## AI 输出长度预算

Turn 理解、AI 梳理、代码注解与 Flowchart 解读的输出 token 上限：不设限 / 512 / 1024 / 2048 / 4096，**默认 4096**。遇到输出截断时会自动以翻倍预算重试一次；重试仍截断会提示调高预算。

## AI 功能开关

- **Wire 会话自动生成 AI 摘要**（设置 → 导入与监测）：开启后，实时同步的新会话会自动理解、归纳并生成总摘要（会产生 AI 调用费用）；未配置激活的 AI 服务时不可开启；
- **启用 AI 代码标注**（设置 → 代码库）：关闭后不再读取或发送任何代码文件内容，已有注解仍可查看，但无法重新生成。

相关设置：

- **摘要格式**：段落式 / 清单式，可多选；
- **Turn 理解注入强度**：精确 / 平衡 / 经济（默认），影响生成数据流解读时参考的 Turn 理解数量。

## 全局 AI 任务管理

批量 AI 任务运行期间（摘要、理解补全、复盘、注解、数据流标签等），底部状态栏出现 AI 任务区：

- 进度条与进度文本（单任务如「会话摘要 3/20」，多任务显示「AI 任务 N 个进行中」）；
- 提供「暂停全部 / 恢复全部 / 取消全部」按钮；点击进度区展开详情，可逐任务暂停、继续或取消；
- 暂停的任务恢复后从断点继续。

## 隐私说明

- API Key 以明文形式保存在本机，共用电脑时请留意；
- 使用云端 AI 服务时，相关内容（会话文本、按功能规则截取的文件片段等）会发送给你配置的 AI 服务商进行处理；viblogy 本身不存储、不分析你的对话内容；
- 使用本地 Ollama 时，所有 AI 处理完全在本机完成。

## 常见问题

**不知道该选哪个预设？**
选你持有 API Key 的服务商，填入 Key，点「测试激活」——成功提示里会显示实际连通的模型。
