# 时间线浏览

时间线是浏览会话的主界面：左侧是项目过滤，中间是按时间排列的会话卡片，右侧是「会话速览」目录列。

## 整体布局

- **左侧栏**：顶部导航「时间线 / 项目 / 笔记」；「项目过滤」区列出「未分类」与各个项目，点击即切换时间线显示内容（单选）；底部「+ 新建项目」。
- **中间时间线**：会话卡片，最新在前。
- **右栏**：默认显示「会话速览」目录；选中某个会话时自动切换为详情侧栏；搜索栏行尾的按钮可随时手动切换（「速览目录」/「详情侧栏」）或关闭（「关闭右栏」），宽度可拖拽。

### 项目过滤

- 「未分类」是过滤区第一项。存在未分类会话时，该行有两个按钮：
  - **自动匹配**：按已有项目名称自动匹配未分类会话，完成后提示扫描与关联数量；
  - **删除**：批量删除全部未分类会话（有确认框，删除后无法恢复）。
- 项目行 hover 出现归档按钮（归档后项目在侧栏隐藏，可在设置中恢复）。
- 没有「全部」入口：时间线始终按具体项目或「未分类」显示。

## 会话卡片

卡片头部显示：标题、项目标签（点击可换项目）、相对时间（悬停显示精确时间），以及「N 轮对话」「已总结」「Todo」「实时」等徽章和来源标记（Kimi Code / Qwen Code）。

关于标题：已生成 AI 摘要的会话始终显示摘要标题；未生成摘要的会话按「设置 → 未生成摘要时的会话标题」显示（默认会话 topic）。

两种查看入口：

- **点击卡片主体**：在时间线内联展开 Turn 列表，再点一次折叠；
- **悬停卡片，点击右上角圆形按钮**（「进入详情视图」）：进入独立的会话详情视图。

展开后还有：

- 「生成总结」/「重新生成总结」按钮（需已配置 AI 服务）；
- 「导出」按钮：勾选轮次后导出选中内容。

### Part 堆叠

超长会话会被自动拆分为多段（Part），以堆叠卡片呈现：顶卡是组内最近活跃的一段。点击顶卡散开整组平铺，组上方出现「收起堆叠」；组内卡片带「Part N / M」标签，点击标签可按同组过滤。

## Turn 与轮次卡片

左侧栏「时间线」导航项上有两个小按钮，控制展开会话内的显示方式：

- **↑ / ↓**：切换轮次顺序（最早在上 / 最新在上），默认最早在上；
- **内容侧切换**：轮次卡片内容区显示「用户输入」还是「assistant 回复」。

轮次卡片操作：

- **单击**：选中；
- **悬停卡片**：出现「理解」（为该轮生成 AI 理解；已有理解时显示「重新理解」，生成中显示「生成中」）与「查看原文」（进入原文视图阅读全文）两个按钮；
- 理解结果块上悬停还有：复制、置入笔记、删除。

## 会话速览列

右栏默认模式。它把已加载会话的每一轮按时间线顺序排成目录：

- 已有理解的轮次：显示理解的「目标」文本 + 绿色「已理解」徽章；
- 未生成的轮次：显示用户或 assistant 发言首句预览 + 灰色「未生成」徽章；
- **点击条目**：时间线自动滚动、展开目标会话并定位到该轮（蓝色描边闪烁提示）；
- **一键校正**：列头按钮。弹窗显示缺失理解的轮数与预估耗时（按每轮约 30 秒估算），确认后批量补齐；生成期间可继续使用其他功能；
- 每条旁还有单条「校正」按钮；
- **走马灯开关**：开启时长文本悬停循环滚动，关闭时静态截断。

## 会话详情视图

从卡片「进入详情视图」进入：

- 顶部：「← 返回」、会话标题、侧栏显示/隐藏按钮、悬停翻阅「← 上一个 / 下一个 →」；
- 按 **⌘K**：从顶部展开搜索栏（再按收起），搜索结果就地替换轮次列表，点击结果跳转对应会话；
- 右侧栏：「开发任务清单」（DevPlan）固定置顶，下方三个页签——「摘要」「问 AI」「复盘」。

## 会话太多时

会话组数量超过上限（500 组）时，时间线只显示最近活跃的部分，顶部横幅提示：「共 N 组会话，时间线仅显示最近活跃的部分，更早会话请用搜索（⌘K）找回」。

从详情视图返回时间线时，会自动滚动定位并展开刚才查看的会话；若它在 Part 堆叠内，会先自动散开该组。

## 常见问题

**找不到某个会话？**
切换左侧栏项目过滤（含「未分类」）找找；或直接用搜索（⌘K）——搜索不受时间线显示范围限制。
