# 搜索

在成百上千轮对话里找回特定内容：一次搜索覆盖会话、摘要、理解、笔记、计划、代码注解等全部内容。

## 入口与快捷键

- 时间线顶部搜索栏常驻；按 **⌘K** 直接聚焦输入框；
- 会话详情视图默认不显示搜索栏，按 **⌘K** 从顶部展开精简搜索栏（再按收起）；
- 支持**逗号分隔**多个关键词（半角、全角逗号均可），每个关键词至少 3 个字；
- 搜索栏可选时间范围：全部时间 / 最近 7 天 / 最近 30 天 / 最近 90 天。

## 搜索覆盖哪些内容

- 会话信息（标题、意图）与 Turn 原文
- AI 摘要（含分组归纳、完成清单）
- Turn AI 理解
- Debug 复盘（意图与分析）
- AI 问答历史
- 笔记
- DevPlan 计划与清单条目
- 代码树节点 AI 注解

## 搜索结果

- 默认按相关度排序；结果列表顶部可切换「最新优先」/「最早优先」（时间序按会话组级生效，优先于相关度）；
- 主列按会话聚合：会话标题 + 「N 个来源命中」，各来源分组展示命中片段，关键词高亮；
- 存在代码注解或 Debug 复盘命中时，额外显示右栏「代码注解与 Debug 复盘」（宽度可拖拽）；
- 标题命中带「匹配：标题」徽章；已过期的理解/注解带「已过期」徽章。

## 点击结果直达

不同命中类型跳到各自的位置：

| 命中类型 | 跳转 |
|---|---|
| Turn 原文 / Turn 理解 | 原文视图；返回时间线后自动定位该轮 |
| AI 摘要 | 会话详情「摘要」页签 |
| Debug 复盘 | 会话详情「复盘」页签 |
| AI 问答 | 会话详情「问 AI」页签 |
| 笔记 | 笔记列表并定位 |
| 代码注解 | 项目视图代码树并定位节点 |
| 会话标题 / 开发计划 | 会话详情 |

## 推荐词与提交轮播

- 搜索栏下方有推荐词行：来自近期 AI 生成内容自动提炼的关键词，点击直接搜索；「换一批」翻页、「刷新推荐」重新生成；推荐词跟随当前项目过滤；
- 选中具体项目时，推荐词行左侧显示该项目最近提交的轮播：点击某条提交会切到项目视图定位该提交，并自动展开其改动文件清单。

## 清空与恢复

点击输入框清除按钮：清空关键词、回到时间线（时间范围筛选保留）；搜索期间右栏自动隐藏，退出搜索后恢复原面板。空结果时可点「清除筛选」同时清空项目与时间筛选。

## 常见问题

**提示「每个关键词至少 3 个字」？**
过短的词无法搜索，把它删掉或换成更完整的词再试。
