# 导入与整理

三条通道把会话送进 viblogy：手动导入、监测文件夹、实时监测。导入之后的去重、版本更新与项目归属，自动完成。

## 三种导入通道

| 通道 | 适用场景 | 说明 |
|---|---|---|
| 手动导入 | 存量导出文件、一次性导入 | 拖拽或选择 `.md` 文件，见[导入第一个会话](../getting-started/first-import.md) |
| 监测文件夹 | 习惯把导出文件存到固定文件夹 | 设置 → 导入与监测 → 监测文件夹 |
| 实时监测 | CLI 边聊边自动同步 | 见[开启实时监测](../getting-started/live-monitor.md) |

### 监测文件夹

1. 在「设置 → 导入与监测 → 监测文件夹」点「添加文件夹」，选择目录；
2. 每行可随时启用 / 停用或删除（删除监测不影响已导入的会话）；
3. 添加或重新启用文件夹时，会立即扫描导入一次其中已有的文件。

之后的行为：

- 监测文件夹中出现新的 `.md` 文件时自动导入，无需确认；
- 每次启动应用，会对启用中的监测文件夹扫描一次，补齐应用未运行期间遗漏的文件（状态栏显示扫描进度，完成后给出数量统计）。

::: warning 只监测文件夹的第一层
监测与启动扫描只在目录**第一层**寻找 `.md` 文件，不进入子目录。请把导出文件直接放在监测目录下。
:::

## 去重与版本更新

- **手动导入**遇到库中已有、且轮数更多的同一会话时，弹出「检测到会话更新」，三个选项：
  - 合并更新到原会话（覆盖旧内容，保留 AI 理解结果）；
  - 作为新会话导入（保留原会话不变）；
  - 取消。
- 与库中完全相同的内容直接跳过；
- **监测导入不会询问**：遇到同一会话的更新版本时自动更新并清理旧版本，已有的 AI 成果保留、不会重复生成。

## 自动项目归属

会话导入后，viblogy 自动尝试把它归入项目（必要时自动创建新项目）。归属成功会提示「已自动关联项目」。

归错了可以手动改：点击会话卡片上的项目标签，在下拉中另选项目，或移回「未分类」。

### 整理未分类会话

左侧栏「未分类」一行（有未分类会话时）提供：

- **自动匹配**：按已有项目名称自动匹配未分类会话，完成后提示扫描与关联数量；
- **删除**：批量删除全部未分类会话（有确认，删除后无法恢复）。

## 导入失败提示

常见错误及含义：

| 提示 | 原因与处理 |
|---|---|
| 无法解析文件：缺少文件元数据 | 不是有效的 Kimi / Qwen 导出文件 |
| 无法解析文件正文：未识别到对话轮次 | 文件内容结构异常 |
| 仅支持 .md 文件 | 格式不对（如 `.html` 网页导出） |
| 保存到数据库失败：磁盘空间不足 | 清理磁盘空间后重试 |
| 保存到数据库失败：数据库被锁定 | 稍后再试 |

失败明细显示在导入区或通知中；批量导入时，单个文件失败不影响其他文件。
