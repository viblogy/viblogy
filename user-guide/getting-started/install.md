# 安装与首次启动

从下载安装包到进入主界面，大约五分钟。

## 系统要求

- macOS 12 或更高版本
- 最低 8 GB 内存（推荐 16 GB，AI 功能与大会话渲染更流畅）

## 安装步骤

1. 访问 [GitHub Releases](https://github.com/liurenpei/viblogy/releases) 页面，下载最新版本的 `.dmg` 文件；
2. 打开 `.dmg`，将 **Viblogy** 拖拽到「应用程序」文件夹；
3. 在启动台或应用程序文件夹中打开 Viblogy。

viblogy 已通过 Apple Developer ID 签名与公证，正常情况可直接打开。

::: tip 遇到 Gatekeeper 提示怎么办
如果系统提示无法打开或无法验证开发者：前往「系统设置 → 隐私与安全性」，找到相关提示，点击「仍要打开」。
:::

## 首次启动引导

首次启动会进入 4 步引导：

1. **欢迎与协议**：产品介绍与功能概览。展开阅读《最终用户许可协议》与《隐私政策》，勾选「我已阅读并同意《最终用户许可协议》和《隐私政策》」后继续。**此步不可跳过。**
2. **激活授权码**：已有授权码可在此输入激活；试用期内可跳过，之后随时在「设置 → 授权许可」中激活。详见[试用与激活](./trial-and-activate.md)。
3. **配置监测文件夹**：选择存放 Kimi 导出文件的文件夹，之后新增的导出文件会自动导入。可跳过，之后在设置中配置。
4. **配置 AI 服务**：填写 AI 服务的 API Key（默认按 Moonshot 预设填充）。摘要、理解等 AI 功能依赖此配置；也可以先不填，直接完成引导。

第 2、3 步可通过右上角 ✕ 跳过整个引导（之后可在设置中重新配置）。完成后进入主界面时间线。

## 你的数据存在哪里

所有数据都保存在本机，不会上传到任何服务器。
