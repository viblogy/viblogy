# 试用与激活

viblogy 提供 30 天全功能试用；激活授权码后可长期使用，延期码可叠加续期。

## 30 天试用

- 安装后即可使用全部功能，无需任何激活操作；
- 「设置 → 授权许可」中会显示试用期剩余天数；
- 剩余 7 天以内，主界面顶部出现提醒横幅，点「去激活」可直达设置页；
- 试用期按本机安装计算：之后即使切换授权账号，试用期也延续计算，不会重新开始。

## 激活授权码

授权码形如 `VIB1.…`。以下三个入口均可激活，效果相同：

- 设置 → 授权许可
- 首次启动引导第 2 步
- 试用到期后的锁定页

粘贴完整授权码，点击「激活」。成功时：永久码提示「授权激活成功」，延期码提示「延期兑换成功」。

::: tip 授权完全离线
授权验证在本机完成，不会上传任何信息。
:::

激活失败时按提示处理：

| 提示 | 处理 |
|------|------|
| 授权码格式不正确 / 内容不完整 | 重新完整复制授权码，注意不要漏字符 |
| 该授权码已兑换过 | 同一授权码只能兑换一次 |
| 授权码无效 | 确认复制完整；如无误请联系发放者 |

## 延期码

- 延期码的天数由发放方决定；
- 可多次兑换，时长累计；
- 试用到期后，兑换一张能覆盖当前日期的延期码即可解锁继续使用；
- 延期码与账号绑定：属于其他账号的延期码不能在当前账号兑换，需先切换到对应账号。

## 到期之后

试用到期后应用进入锁定页（「免费使用期已结束」）。**你的数据完好保存在本地**，输入授权码激活后全部恢复。

若看到「检测到系统时间异常」提示：校准系统时间后重启应用，或直接激活授权码。

尚未购买？锁定页底部附有购买渠道说明。

## 切换授权账号

已激活状态下，授权卡片上有「使用其他授权码」入口。输入其他账户的授权码会触发账号切换，规则如下：

- 不同账户的授权时长**不可叠加**，只能切换过去使用；
- 目标账户已存在：切换后其数据原样恢复，无需导入备份；
- 目标账户不存在：为其新建空白数据库，AI 服务配置会继承，会话、笔记等业务数据从零开始；
- 当前账户的数据完整保留——之后重新输入它的授权码即可切回；
- 切换需要重启应用。

## 查看授权状态

激活后的授权卡片显示：授权邮箱、适用大版本、激活日期，以及「✓ 适用于当前版本」标记。若授权对应其他大版本，会显示「⚠ 需升级」及升级提示。

卡片上还有「停用授权」按钮：停用后可随时用原授权码重新激活。
