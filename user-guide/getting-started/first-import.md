# 导入第一个会话

把一份 Kimi 或 Qwen 导出的会话文件拖进来，几秒钟后它就出现在时间线上。

## 准备工作

你需要一份 `.md` 格式的会话导出文件：

- 在 Kimi Code 或 Qwen Code 中使用各自的会话导出功能，导出为 `.md`；
- 两种格式 viblogy 都能自动识别，无需手动选择；
- 目前仅支持 `.md` 导出（网页版 `.html` 导出暂不支持）。

## 导入操作

在时间线视图，三种方式任选：

1. **拖拽**：把 `.md` 文件拖到时间线区域，底部出现「释放以导入」时松手；
2. **点击选择**：点击时间线的拖放区（时间线为空时，空态页有「手动导入」按钮），在文件选择器中挑选——支持多选批量导入；
3. **快捷键**：按 `⌘⇧I` 打开文件选择器。

批量导入时界面显示进度（「正在导入 2 / 5」），完成后给出汇总：「导入完成：N 个成功，M 个已存在，K 个失败」。

## 你会看到什么

- 时间线出现会话卡片，会话会自动归入匹配的项目（归错了可以手动调整）；
- **点击卡片主体**：内联展开该会话的全部 Turn（对话轮次）列表；卡片右上角的最大化按钮可进入独立的会话详情视图；
- **悬停某个 Turn 卡片**：出现「查看原文」按钮，点击进入原文视图阅读全文；单击 Turn 卡片则是选中它。

## 重新导入同一会话

会话继续对话后重新导出、再次导入时，viblogy 检测到这是同一会话的更新版本（「检测到会话更新」，并显示轮次变化），提供三个选项：

- **合并更新到原会话**：覆盖旧内容，已有的 AI 成果（Turn 理解、会话摘要等）保留，无需重新生成；
- **作为新会话导入**：原会话保持不变；
- **取消**。

导入与库中完全相同的内容时会自动跳过，计入汇总中的「已存在」。

## 常见问题

**导入时提示「仅支持 .md 文件」**
检查导出格式：需要 Kimi / Qwen 的 `.md` 导出，`.html` 网页导出暂不支持。

**导入成功但时间线上找不到会话**
时间线按项目筛选显示。切换左侧栏的项目过滤，找到会话所属的项目即可。
