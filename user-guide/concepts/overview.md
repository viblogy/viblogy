# 功能总览

viblogy 把散落的 AI 对话，变成**可读的工作进度、可复盘的调试教训、可溯源的代码地图**。这张功能地图按「你想做什么」组织，每一项链接到对应的操作指南。

## 把对话收进来

| 想做的事 | 去哪里 |
|---|---|
| 导入 Kimi / Qwen 导出的会话 | [导入第一个会话](../getting-started/first-import.md)、[导入与整理](../guides/import-and-organize.md) |
| 让新对话自动、实时入库 | [开启实时监测](../getting-started/live-monitor.md) |
| 重复导入不产生垃圾、换版本不丢 AI 成果 | [导入与整理](../guides/import-and-organize.md) |
| 会话自动归入项目，归档做完的项目 | [导入与整理](../guides/import-and-organize.md)、[项目与归档](../guides/projects.md) |
